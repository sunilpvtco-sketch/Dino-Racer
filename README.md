# DIANO RACER — FINAL GITHUB EDITION

A mobile-first 3D endless jungle runner built with HTML, JavaScript and Three.js.

## Included
- Real 3D T-Rex GLB
- Muddy jungle road
- Jungle environment
- Three-lane endless running
- Jump
- Slide
- Obstacles
- Coins
- Magnet
- Speed Boost
- Shield
- Extra Life
- Lives
- Score and distance
- Best score persistence
- Mobile swipe controls
- Desktop keyboard controls
- PWA support
- Offline caching
- GitHub Pages deployment

## Start locally
Because browsers restrict some module/file loading when opening HTML directly from `file://`, use a small local HTTP server if testing on a computer.
