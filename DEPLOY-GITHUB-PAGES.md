# DIANO RACER — GitHub Pages Deployment

## 1. Create repository
Create a **Public** repository on GitHub, for example:

`diano-racer`

## 2. Upload
Upload the **contents of this folder**, not the ZIP itself.

The repository root must contain:

- `index.html`
- `manifest.json`
- `sw.js`
- `js/`
- `assets/`

## 3. Enable Pages
GitHub → Repository → **Settings** → **Pages**

Set:

- Source: **Deploy from a branch**
- Branch: `main`
- Folder: `/ (root)`

Click **Save**.

## 4. Open the game
After GitHub finishes publishing, open the Pages URL shown by GitHub.

## 5. Android installation
Open the game in Chrome → browser menu → **Add to Home screen / Install app**.

## Important
This is a static web game. It does not require a Node server, database or paid hosting.
